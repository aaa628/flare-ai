# site/assets: third-party files used by the home page

- **taste-skill kit** (`system.css`, `system.js`, `layout/`, `motion/`, `ui/`, `moments/`, `backgrounds/`, `icons/`):
  copied unchanged from https://github.com/Leonxlnx/taste-skill (version 2.5.1, MIT licence, © 2026 Leonxlnx).
  Only the parts `index.html` uses are included. Do not edit these files; page-specific CSS lives in `../css/landing.css`.
- **Fonts** (`fonts/`): Funnel Display, Funnel Sans and DM Mono, latin subsets downloaded from Google Fonts
  (SIL Open Font License 1.1). Self-hosted so the site works offline and under a strict Content-Security-Policy.

The screenshots in `../img/` are captures of this site's own tool pages (`app.html`), made by the team.
